# Def Jam: Fight for NY - Complete Blazin' Move Archive

## About

This project is a fan-made archive documenting all 82 Blazin' Moves from **Def Jam: Fight for NY**.

The goal is to preserve the choreography, animation details, and personality behind each move instead of only listing their names.

## What is documented?

Each Blazin' Move includes:

- Move name
- Choreography breakdown
- Animation details
- Fighting style characteristics
- Crowd interaction and personality notes
